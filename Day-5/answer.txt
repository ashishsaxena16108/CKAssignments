Q1. Find and terminate the top memory-consuming process on your system.
Ans. kill $(ps aux --sort %mem | tail -n 1 | tr -s ' ' | cut -d " " -f 2)

Q2. Create a user named devops and grant them sudo privileges.
Ans. sudo adduser devops
     sudo usermod -aG sudo devops

Q3.Connect to a remote server, create a directory, and copy files into it using SCP.
Ans.scp -r ./Documents/test sushant@10.1.210.41:./Downloads

Q4.List all active processes and save only those containing the word java into a file.
Ans. ps aux | grep "java" | xargs > /home/ashish-saxena/Documents/test/alljavaprocesses.txt
     head /home/ashish-saxena/Documents/test/alljavaprocesses.txt
     Output:ashish-+ 72817 0.0 0.0 9144 2304 pts/1 S+ 14:54 0:00 grep --color=auto java

Q5.Generate an SSH key pair and configure it for two different remote servers.

     ssh-copy-id sushant@10.1.210.41
Q6.Find all lines containing “error” in /var/log/syslog and redirect them to errors_found.txt
Ans.grep "error" /var/log/syslog > ./Documents/test/errors_found.txt

Q7.Find all .conf files in /etc, sort them alphabetically, and save to conf_list.txt.
Ans.find /etc -name '*.conf' | sort > ./Documents/test/conf_list.txt

Q8.Display the total number of unique shell types listed in /etc/passwd and save to shell_count.txt
Ans. cut -d: -f7 /etc/passwd | uniq -c > ./Documents/test/shell_count.txt
     cut -d: -f7 /etc/passwd | uniq |wc -l >> ./Documents/test/shell_count.txt

Q9.Reset the current user password and reboot the system form shell.

     sudo reboot
